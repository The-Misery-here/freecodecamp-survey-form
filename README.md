# freeCodeCamp Survey Form

My first certification project from the **freeCodeCamp Responsive Web Design** curriculum.

## About the Project

A survey form built using HTML to collect user feedback about the freeCodeCamp platform.

The form includes personal information fields, dropdown menus, radio buttons, checkboxes, and a comments section.

## Technologies Used

- HTML5
- Semantic HTML
- HTML Forms

## What I Learned

- Structuring a webpage using HTML.
- Working with form elements such as `input`, `select`, and `textarea`.
- Using labels and input attributes.
- Understanding radio buttons and checkboxes.
- Organizing form sections using `fieldset` and `legend`.
- Applying basic HTML form validation using attributes such as `required`, `min`, and `max`.
